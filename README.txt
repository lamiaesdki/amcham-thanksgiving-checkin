AMCHAM THANKSGIVING DINNER 2026 — CHECK-IN PWA

Event: Tuesday, 24 November 2026
Venue: Hyatt Regency Casablanca

Features: 85 bookings / 108 ticket slots; hybrid company and attendee search; individual and full-booking check-in; separate payment status; seating page with 10 default tables and 10 seats per table; editable table count and capacity; assign existing attendees or add manual guests; offline PWA; Excel/CSV import; JSON backup/restore; attendance CSV export.

No attendee identities are invented. Names not present in the source workbook remain marked as name needed. Seating is assigned individually; manual additions create individual booking records. Table count and capacity are starting assumptions and can be changed in Seating settings.

Install: Host on HTTPS, open in Safari, Share → Add to Home Screen, then open once online to cache the offline app. Data is device-local; export JSON backups regularly.
