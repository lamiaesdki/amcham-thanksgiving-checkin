AMCHAM THANKSGIVING DINNER 2026 — CHECK-IN PWA

Event: Tuesday, 24 November 2026
Venue: Hyatt Regency Casablanca

FEATURES
- 85 preloaded bookings representing 108 ticket slots.
- Search by company, booking contact, or attendee name.
- Check-in for one attendee or the entire booking.
- Payment status is independent from check-in.
- Seating Plan page with 10 default tables and 10 default seats per table.
- Click a table to view its roster, assign a registered attendee, remove an assignment, or add a manual guest name.
- Table count and seats per table are editable in Seating settings.
- Over-capacity tables are flagged; reducing the capacity does not delete assigned guests.
- Manual table assignment is kept separate from the registration booking data.
- Excel/CSV import, JSON backup/restore, attendance CSV export.
- Offline PWA; data stored locally on this device.

ATTENDEE DATA
The workbook provides booking rows and ticket quantities, not a verified name for every seat. Existing source contact names are retained; unnamed ticket slots are marked as requiring a name. No attendee identity has been invented.

SEATING RULES
- Initial working assumptions are 10 tables × 10 seats.
- Both values can be changed later.
- Existing attendee records can be assigned to tables from the Seating Plan.
- Manual guests added directly to a table are created as individual manual booking entries.
- Table occupancy uses individual attendee assignments first, falling back to booking-level table assignments.
- If capacity is exceeded, an over-capacity warning is displayed; no guest is deleted.

PAYMENT / ARRIVAL
Payment status does not automatically check in an attendee. Group check-in checks in all attendees on that booking; individual check-in affects only the selected attendee.

INSTALL
1. Host files on an HTTPS static host such as GitHub Pages.
2. Open the HTTPS URL in Safari on iPhone.
3. Share → Add to Home Screen.
4. Open once while online to cache offline app files.
5. Confirm 85 bookings / 108 ticket slots, then export a JSON backup.

DATA SAFETY
- No cloud synchronization; data and seating configuration are local to the device.
- Use Export backup regularly and store JSON in Files/iCloud Drive.
- Import replaces the current list and resets check-ins after confirmation.
